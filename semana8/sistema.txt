El comando uname -a muestra información del sistema operativo, la versión de Linux, la arquitectura y 
otros datos técnicos del equipo.

El comando whoami muestra el nombre del usuario que está utilizando el sistema. 
En este caso el usuario es "codespace".

Conocer esta información es útil al administrar un servidor porque permite identificar el 
sistema que se está usando, verificar configuraciones y saber con qué usuario se están ejecutando 
las tareas o comandos.
